# Hi, I'm Justin

By day, I'm a Principal GTM Engineer at [Jamf](https://www.jamf.com/). Outside of work I build small on-device Mac voice tools and other OSS.

## What I'm working on

- [Transcripted](https://github.com/r3dbars/transcripted) — record meetings and dictation on a Mac, transcribe locally, save Markdown
- [Said](https://github.com/r3dbars/said) — private on-device live captions for anything the Mac plays
- [Um](https://github.com/r3dbars/um) — menu bar filler-word counter. On-device. No account. No subscription
- [Recite](https://github.com/r3dbars/recite) — local text-to-speech for Mac, without cloud voice APIs
- [Antibody](https://github.com/r3dbars/antibody) — AI evals: flag a failure once, then catch it forever
- [Nightshift](https://github.com/r3dbars/nightshift) — put idle AI hardware to work overnight
- [Unspool](https://github.com/r3dbars/Unspool) — morning pages as local Markdown
